# 📚 Library Book Search & Sort System

A simple console-based Library Management System developed in C Language for the Algorithm course project.

## 📖 Project Overview

This project allows users to manage book records using a command-line interface. The system demonstrates the implementation of fundamental algorithms in C programming.

The main objective of this project is to apply searching and sorting algorithms in a practical scenario.

---

## 🚀 Features

* Add New Books
* Display All Books
* Sort Books by Book ID
* Search Books by Book ID
* Menu-Driven Console Interface
* Efficient Data Management Using Arrays

---

## 🛠️ Algorithms Used

### Quick Sort

Used to sort books based on their Book ID.

**Average Time Complexity:**
O(n log n)

### Binary Search

Used to quickly search for a book by its Book ID after sorting.

**Time Complexity:**
O(log n)

## ▶️ How to Run

1. Compile the program:

```bash

```

2. Run the program:

```bash

```

or on Windows:

```bash
library.exe
```
